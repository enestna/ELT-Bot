# 🐟 Tuna Chat AI Agent - Reported Speech Tutor

Tuna Chat is a professional **AI Agent** built with **ReactJS** and **Node.js** that specializes in teaching English "Reported Speech". 

## 🚀 Features
- **AI-Powered Learning:** Uses Groq (Llama 3.3) for instant and accurate grammar conversions.
- **Agent Personality:** Acts as a specialized English Teacher.
- **Smart History:** Saves all your past lessons into a local JSON database.
- **Modern UI:** Responsive, dual-panel dark mode design.

## 🛠️ Tech Stack
- **Frontend:** React, Axios, CSS3
- **Backend:** Node.js, Express
- **AI Platform:** Groq Cloud API
- **Database:** Local JSON File System

## ⚙️ Installation
1. Clone the repository: `git clone https://github.com/enestna/tuna-chat-ai-agent`
2. **Server Setup:**
   - `cd server`
   - `npm install`
   - Create a `.env` file and add: `GROQ_API_KEY=your_api_key_here`
   - Start: `node server.js`
3. **Client Setup:**
   - `cd client`
   - `npm install`
   - Start: `npm run dev`
